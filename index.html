Sign-in method

How staff get in. Code: a 6-digit code proves the e-mail is really theirs (safest). E-mail only: an address you added is let in as soon as it is typed; anyone else sees "Contact your admin". Admin accounts always use a code, and every e-mail-only sign-in is written to the Changes sheet.

Check sign-in e-mail

If someone says the sign-in code never arrives, type their address here. It tells you whether they are on the list and sends them a test e-mail.

Label register – upload from the label generator

In the label tool click Export Bundle Register (CSV), then upload that file here (CSV or Excel). The QR on each label holds only an ID; this register tells the app which bundle the ID belongs to. Every upload is added to the register: new IDs are added, IDs already there are updated, and nothing is removed. Use Download register to keep a copy for future reference.
